# Roadmap do DocWord

## Concluído na base 0.2

- [x] Motor rich text por seleção.
- [x] Estrutura do código separada em app, editor e serviços.
- [x] Formato nativo `.docword` em Delta JSON.
- [x] Abrir e salvar documento.
- [x] Exportar texto simples.
- [x] Undo/redo e formatação rich text pelo motor do editor.
- [x] Atalhos Ctrl+N, Ctrl+O e Ctrl+S.
- [x] Indicador de alterações não salvas.
- [x] Contagem de palavras/caracteres.
- [x] Zoom.
